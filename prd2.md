# Growth Budget — Add-on PRD: Growth Objectives

Add-on PRD

### Growth Objectives

## Problem statement

Users identify skills they want to develop through job descriptions, performance feedback, career aspirations, or personal interests.

However, these development goals are often scattered across notes, learning resources, and task lists.

The Growth Objectives module provides a central place to capture these goals, connect them to learning activities, and track tangible progress toward achieving them.

The module should help users answer three questions:

* What capabilities do I want to develop, and why?

* What am I doing to develop those capabilities?

* How will I know when I have achieved an objective?

## Create and manage objectives

Users must be able to create development objectives independently of existing categories or curricula.
Each objective should support the following properties:

Title: Capability or outcome to develop
Motivation: Why the objective matters
Priority
Status
Target date
Success criteria: User-defined evidence of achievement

This should be in a new tab, not on the home page.
Should be restricted to max 3 objectives, any additional objective requies the existing ones to be completed / deleted.

## Acceptance criteria

The add-on is considered functionally complete when:

* Users can create, edit, archive, and mark objectives as achieved.

* Users can associate objectives with existing categories, topics, and learning sessions.

* The dashboard displays up to three active objectives.

* Each objective displays accumulated learning hours and the last activity date.

* A single learning session can contribute to multiple objectives without double-counting its duration against the weekly budget.

* Users can achieve an objective independently of associated curriculum completion.

* The core learning tracker remains fully functional when the module is disabled.

Design principle: Growth Objectives should help users connect their learning to meaningful outcomes without creating another compulsory list of things to complete.
